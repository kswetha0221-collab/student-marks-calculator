# Student Marks Calculator

A beginner-friendly web project that calculates a student's total marks, percentage, grade, and result status.

## Features
- Enter a student name and marks for five subjects
- Validates marks from 0 to 100
- Calculates total marks out of 500 and percentage
- Displays a grade and pass status
- Responsive layout for desktop and mobile screens

## Technologies
- HTML
- CSS
- JavaScript

## How to run
1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Enter the student's name and subject marks.
4. Select **Calculate Result**.

## Grade rules
- A+: 90% and above
- A: 80–89.99%
- B: 70–79.99%
- C: 60–69.99%
- D: 50–59.99%
- E: below 50% if all subjects are passed
- F: if any subject is below 35

These are sample grading rules for this project; actual school or college rules may differ.
